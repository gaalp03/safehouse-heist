Privacy

Safehouse Heist collects anonymous gameplay statistics through ByteBrew (a CrazyGames analytics partner) so we can see where the game is too hard or confusing and make it better.

What we collect: game events such as a heist starting or ending, being spotted or caught, time played, level, difficulty, device type (mobile / tablet / desktop) and game version.

What we never collect: your name, email, CrazyGames account or user ID, chat, or anything you type.

Device ID: ByteBrew stores a random anonymous ID locally in your browser so sessions from the same device can be counted together. It is not linked to who you are.

Opting out: press Analytics: Off below (or the Privacy link in the main menu). The choice is saved in this browser and nothing more is sent. Clearing your browser data removes the device ID.

Analytics only run when the game is played on CrazyGames. Questions: contact us through the game's CrazyGames page.
